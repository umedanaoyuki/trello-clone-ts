# trello-clone-ts

Vite + React 17 + TypeScript で作成されたプロジェクトです。

## セットアップ

依存関係をインストール：

```bash
npm install
```

## 開発サーバーを起動

```bash
npm run dev
```

## ビルド

```bash
npm run build
```

## プレビュー

```bash
npm run preview
```

## 技術スタック

- **Vite** - ビルドツール
- **React 17** - UI ライブラリ
- **TypeScript** - 型安全性
- **ESLint** - リンター
